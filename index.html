Agentic Workflow Patterns
▶ Sequential Workflow
Agents run one after another in a chain. Agent 1 completes → hands off to Agent 2 → Agent 3. Best for tasks with strict order dependencies (e.g., spec → code → test → review).
⊕ Parallel Workflow
Meta Agent orchestrates multiple agents running simultaneously. All results converge at an Aggregator. Best for independent subtasks — multiple files, parallel feature branches.
🔁 Self-Reflection Workflow
Adds a quality control feedback loop. Meta Agent + Agent 1 does the work → Verifier checks output → if fails, feedback sent back to retry. Best for code review, security checks.

The Prompt Framework
copilot / claude prompt template
# USE THIS TEMPLATE for every feature request to AI CONTEXT: [What does this code sit next to?] - Module: src/services/payments.py - Related: models/order.py, repositories/payment_repo.py TASK: [One clear imperative verb sentence] - Implement async Stripe payment processing CONSTRAINTS: - Python 3.12, async/await - Type hints + Google docstring required - Raise PaymentDeclinedError on 402 - No global state OUTPUT: - Function in src/services/payments.py - Unit tests in tests/unit/test_payments.py - Mock stripe client in tests
Vibe Coding Anti-Patterns
  • Never accept AI code without running the full pre-commit hook chain locally
  • Never use "LGTM" reviews on AI-generated PRs — check logic, not just style
  • Never let AI write to production config files without human review of every line
  • Never accept generated code that has no tests attached — make AI write tests first (TDD prompting)
  • Never skip type checking on AI output — mypy --strict always
  • Never give AI agent access to production secrets or live DB credentials
  • Always check AI-generated SQL for injection risks even if using ORM
  • Always run Bandit on AI-generated security-adjacent code (auth, crypto)

04 Critical Gap
Evaluation & Testing Framework
You said this is your weakest area. This section is your recovery plan. Treat testing as a first-class feature, not an afterthought.

As AI autonomy advances, evaluation and testing become the primary constraint on how fast you can go. When agents generate code faster than humans can review it, the bottleneck shifts decisively from code creation to verification. Evaluation must become continuous and embedded — not periodic and manual.

The AI-Native Testing Pyramid
Unit Test — AAA Pattern
python — pytest
import pytest from unittest.mock import AsyncMock, patch from decimal import Decimal from src.services.payments import process_payment @pytest.mark.asyncio @pytest.mark.parametrize("amount,expected_status", [ (Decimal("100.00"), "captured"), # happy (Decimal("0.01"), "captured"), # edge: min (Decimal("9999.99"), "captured"), # edge: max ]) async def test_process_payment_success( amount: Decimal, expected_status: str, mock_gateway: AsyncMock, sample_order: Order, ) -> None: # Arrange sample_order.total = amount mock_gateway.charge.return_value = ChargeResult( transaction_id="txn_123", status=expected_status, ) # Act result = await process_payment(sample_order, mock_gateway) # Assert assert result.status == expected_status mock_gateway.charge.assert_called_once_with(amount)
Property-Based Testing (Hypothesis)
python — hypothesis
from hypothesis import given, settings from hypothesis import strategies as st from src.core.pricing import calculate_discount # Let hypothesis find edge cases AI might miss @given( price=st.decimals(min_value="0.01", max_value="9999"), discount_pct=st.floats(min_value=0, max_value=100), ) @settings(max_examples=500) def test_discount_never_negative( price: Decimal, discount_pct: float ) -> None: result = calculate_discount(price, discount_pct) # Invariant: final price always >= 0 assert result >= Decimal("0") # Invariant: never exceeds original assert result <= price

05 Security Layer
Security, Risk & Governance
New risk classes introduced by AI-native development require structural responses, not manual review.
Prompt Injection
Malicious input in user data manipulates agent instructions and causes unintended code execution or data exfiltration.
CRITICAL
Credential Leak
AI agents trained on internal code may reproduce secrets, tokens, or API keys in generated output.
CRITICAL
Scope Creep / Hallucination
Agents modify files or dependencies beyond their mandate. Self-reflection loops catch this — humans must approve diffs.
CRITICAL
Dependency Confusion
AI imports non-existent or typosquatted packages. All imports validated against approved package list before install.
HIGH
Training Data Poisoning
AI models fine-tuned on vulnerable code reproduce those patterns. CodeQL and Bandit run on ALL generated code.
HIGH
Attribution Loss
AI-generated changes not linked to human approver. Every commit must have human sign-off. Agent identity ≠ human identity.
MEDIUM
